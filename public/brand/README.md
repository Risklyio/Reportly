# Reportly.io brand assets

Place your logo file here (do not commit secrets).

## Required for the top menu

Save your attached logo as:

```
public/brand/reportly-logo.png
```

**Recommended:** PNG with a **transparent** background so it looks correct on the teal header (`#1a3233`).

If your file is only available with a black background, it will still work, but you may see a dark rectangle behind the logo on the header.

## Optional

| File | Use |
|------|-----|
| `reportly-logo.png` | Top navigation (required) |
| `reportly-icon.png` | Browser tab favicon (square crop of the icon) |

After adding the file, commit and push so Vercel redeploys. Hard-refresh the browser (Ctrl+Shift+R) if you still see the old placeholder logo.
